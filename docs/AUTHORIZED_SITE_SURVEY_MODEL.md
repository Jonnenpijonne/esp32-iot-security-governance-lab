# Authorized Site Survey Model

This document defines a public, generic model for authorized site readiness documentation.

The model is for approved building and technical area documentation work. It does not define scanning, discovery, intrusion testing or operational use.

## Purpose

The purpose is to document readiness in a controlled way:

- What area was reviewed.
- Who owned the review.
- What points were documented.
- What checks were completed.
- Where evidence is stored.
- What limitations remain.

## Scope

Included:

- Manual network point records.
- Local environmental readiness notes.
- Device readiness checks.
- Evidence references.
- Limitations.

Excluded:

- Unapproved discovery.
- Network scanning.
- Port scanning.
- Credential testing.
- Wireless discovery.
- Customer-specific details in this public repository.

## Public repository boundary

This repository may contain synthetic examples and reusable templates only.

Real site names, room names, diagrams, network details, device identifiers and evidence packages must be stored in controlled private project locations.

## Minimum review fields

A site readiness record should include:

- Review id.
- Authorization or permission reference.
- Site label.
- Area label.
- Review owner.
- Network points documented.
- Device readiness checks.
- Evidence location.
- Known limitations.

## Principle

Authorized review first. Evidence second. Automation only after scope, permission and data boundaries are clear.
