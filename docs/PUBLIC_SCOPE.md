# Public Scope

This document defines the intended public scope of the repository.

The repository is a public governance lab. It should remain generic, reusable and safe to share.

## Included material

This repository may contain generic architecture notes, risk and control documentation, lifecycle documentation, update and rollback governance, privacy and telemetry guidance, change examples, evidence models, validation scripts and synthetic examples.

## Out-of-scope material

Project delivery details should be stored outside this public repository.

Out-of-scope material includes delivery architecture, operating environment details, device inventory, network details, release records, approval records, evidence packages and environment-specific configuration.

## Example data

Examples in this repository should be clearly synthetic.

## Review checklist

Before publishing changes, check whether the material is reusable, generic, safe to share and appropriate for a public portfolio repository.

## Principle

Keep public material generic. Keep project-specific material controlled separately.
