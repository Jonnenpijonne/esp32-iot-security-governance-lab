# License Policy

This project uses the Apache License, Version 2.0.

## Why Apache-2.0

Apache-2.0 is used because this repository is intended to be stronger than a minimal permissive MIT-style portfolio license while still remaining reusable.

Apache-2.0 is appropriate for this project because it provides:

- Clear permission to use, modify and distribute the work.
- Explicit patent-license language.
- Contribution handling.
- NOTICE-file support.
- Clear warranty and liability disclaimers.

## Project scope

The license applies to the public repository contents, including:

- Documentation.
- Python models.
- Firmware skeleton code.
- Synthetic examples.
- Evidence templates.
- GitHub Actions workflows.

## What the license does not mean

The license does not mean that the repository is:

- Production-ready firmware.
- Certified security tooling.
- A customer delivery package.
- A classified project record.
- Approved for safety-critical use.
- Approved for operational deployment.

## Public/private boundary

This repository is public and synthetic.

Do not add:

- Customer data.
- Real site data.
- Real room labels.
- Real network inventories.
- Credentials.
- Keys.
- Protected environment evidence.
- Classified or sensitive operational records.

Real project use should maintain controlled private annexes for project-specific evidence, approvals and deployment details.
