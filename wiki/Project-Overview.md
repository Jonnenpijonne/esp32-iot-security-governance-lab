# Project Overview

This project is a governance-first ESP32 and embedded edge-device security lab.

It is designed as a public portfolio project and reusable reference baseline for regulated or sensitive environments.

## What it demonstrates

The project demonstrates how a small embedded-device project can include:

- Firmware baseline.
- Device identity.
- Synthetic sensor data.
- Retention boundary.
- Event visibility.
- Readiness scoring.
- Network point inventory review.
- Defensive exercise gates.
- Protection scoring.
- Interference observation.
- EMB3D-style property mapping.
- KATAKRI-style public/private boundary.

## What it is not

This project is not:

- Production firmware.
- A customer site report.
- A classified project record.
- A penetration testing toolkit.
- A drone-control project.
- A medical decision system.
- A certification claim.

## Core idea

Small technical systems become serious when they connect to physical space, device identity, evidence, environment data or regulated operations.

This repository shows how to keep that work controlled, reviewable and auditable.
