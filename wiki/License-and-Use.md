## Why Apache-2.0

Apache-2.0 provides a stronger public-project license posture than a minimal MIT-style license while remaining reusable for portfolio, learning and reference use.

It includes:

- Permission to use and modify.
- Patent-license language.
- Contribution handling.
- NOTICE-file support.
- Warranty and liability disclaimers.

## Intended use

This repository is intended for:

- Portfolio evidence.
- Learning.
- Governance reference.
- Defensive assurance examples.
- Synthetic embedded-device security modeling.

## Not intended for

This repository is not intended as:

- Production firmware.
- Certified security tooling.
- A customer delivery package.
- A protected project record.
- A deployment-ready system.

## Private project use

If this repository is adapted for real project use, keep real project records in controlled private annexes.
