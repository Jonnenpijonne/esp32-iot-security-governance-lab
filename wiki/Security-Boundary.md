# Security Boundary

This repository is intentionally public and synthetic.

## Allowed public content

Allowed content includes:

- Synthetic examples.
- Generic documentation.
- Reusable governance models.
- Public validation scripts.
- Firmware skeletons without real deployment data.
- Evidence templates.

## Not allowed in this public repository

Do not add:

- Real customer data.
- Real site names.
- Real room labels.
- Real device inventories.
- Real network addresses.
- Credentials.
- Keys.
- Production secrets.
- Protected environment evidence.
- Classified or sensitive operational records.

## Real project use

Real project use should maintain private annexes for:

- Scope.
- Approvals.
- Device inventory.
- Evidence.
- Environment details.
- Risk decisions.
- EMB3D mappings.
- Acceptance records.

## Principle

The public repository demonstrates the method.

Private annexes contain project-specific truth.
